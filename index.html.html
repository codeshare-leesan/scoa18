MISSION 00

오늘의 미션: 탐사 로봇을 지켜라

화성 탐사 로봇 루미가 먼 길을 달리고 있어요. 우리는 실제 온도 센서 대신 가변저항 손잡이로 20~80도의 가상 배터리 온도를 설정합니다. PC의 AI가 짧은 안내 문장을 쓰고 신호등 색을 제안해요. 컴퓨터가 답을 확인한 뒤, Arduino가 불을 켭니다.

① 가변저항→② Arduino A0→ USB 시리얼 →③ Python→ 로컬 API →④ Ollama AI→ JSON →⑤ Python 확인→ USB 시리얼 →⑥ LED

여기서 JSON은 AI의 답을 항목별로 정리한 글 상자입니다. AI는 {"light":"Y","message":"가상 온도가 높아지고 있어요."}처럼 답하고, Python은 Y 한 글자만 Arduino로 전송합니다. Arduino 안에서 Ollama가 실행되는 것은 아닙니다.

가상 온도신호등미션 속 의미
20~39도G · 초록계속 탐사
40~59도Y · 노랑잠깐 점검
60~80도R · 빨강탐사를 멈추고 식히기

성공 기준: 손잡이를 천천히 돌려 3색이 순서대로 켜지고, PC 화면에 AI가 만든 한국어 설명이 나타납니다. AI 응답에는 몇 초 이상 걸릴 수 있어요.

PREPARE 01

준비물과 배선 지도

  • Arduino UNO R3 또는 UNO R4 1개, 데이터 전송 가능한 USB 케이블 1개, Windows PC 1대
  • 10kΩ 가변저항 1개, 브레드보드 1개, 점퍼선 여러 개
  • 빨강·노랑·초록 각각 따로 있는 LED 3개와 220~330Ω 저항 3개
3색 신호등 모듈을 이미 갖고 있다면 GND가 공통이고 R/Y/G에 HIGH를 넣으면 켜지는 제품인지 먼저 확인하세요. 모듈에 저항이 내장되어 있는지도 확인해야 합니다. 이 교재의 배선은 일반 LED 3개 기준입니다. 공통 양극 또는 LOW 활성 모듈은 코드가 달라집니다.
부품 쪽Arduino 쪽메모
가변저항 바깥쪽 ①5V두 바깥쪽을 바꾸면 회전 방향만 반대
가변저항 가운데A0변하는 숫자를 읽는 선

그림은 연결 관계를 나타냅니다. LED 저항은 3개를 각각 사용하고, 브레드보드의 GND 줄을 공통으로 연결합니다.

배선을 바꿀 때는 먼저 USB를 뽑으세요. LED에는 저항을 빼먹지 말고, 5V와 GND를 직접 이어 붙이지 마세요.
INSTALL 02

Python 3.11.9 설치

이 교재는 사용 경험이 있는 Python 3.11.9, Windows 64비트 설치 파일로 통일합니다. 이미 Python 3.11이 있다면 설치를 건너뛰고 버전부터 확인해도 됩니다.

  1. Python 3.11.9 공식 페이지에서 Windows installer (64-bit)를 클릭합니다.
  2. 설치 화면 맨 아래의 Add python.exe to PATH (또는 Add Python to PATH)를 체크합니다.
  3. Install Now를 누르고 설치가 끝나면 창을 닫습니다. 새 명령 프롬프트(cmd)를 엽니다.
  4. 아래 명령을 한 줄씩 입력합니다.
cmd에서 입력
python --version
py -3.11 --version
py -3.11 -m pip --version

버전이 Python 3.11.9처럼 보이면 성공입니다. 다른 3.11.x라도 코드 실행은 가능합니다. python 명령이 안 되지만 py -3.11이 되면 교재의 실행 명령을 그대로 사용하세요. 둘 다 안 되면 설치 파일을 다시 실행해 PATH 설정과 Python Launcher 설치를 확인합니다.

시리얼 통신 도구 딱 하나 설치

cmd에서 한 줄씩
py -3.11 -m pip install pyserial
py -3.11 -c "import serial; print(serial.__version__)"

pyserial은 PC와 Arduino의 USB 시리얼 통신을 돕습니다. Ollama Python 패키지와 requests는 이 교재에 필요하지 않습니다. Python 기본 도구인 urllib과 json을 사용합니다. 학교 PC에서 설치가 막히면 교사에게 계정 권한을 확인해 달라고 하세요.

INSTALL 03

Ollama 설치와 AI 모델 받기

  1. Ollama 공식 Windows 다운로드에서 설치 파일을 받아 실행합니다. Windows 10 22H2 이상 또는 Windows 11을 준비합니다.
  2. 설치가 끝나면 새 cmd 창을 열고 아래 명령을 한 줄씩 실행합니다. Ollama 앱이 백그라운드에서 실행됩니다.
cmd에서 한 줄씩
ollama --version
ollama pull qwen2.5:1.5b
ollama ls
ollama run qwen2.5:1.5b

pull은 첫날 인터넷을 사용해 약 1GB 모델 파일을 내려받습니다. run을 실행하면 AI에게 안녕! 한 문장으로 인사해 줘.라고 입력해 보세요. 답을 받으면 Ctrl+C로 대화를 끝냅니다. 모델 이름에는 반드시 :1.5b를 붙입니다. 생략하면 훨씬 큰 기본 모델을 받을 수 있습니다.

Ollama는 같은 PC의 http://127.0.0.1:11434에서 기다립니다. localhost/127.0.0.1은 내 컴퓨터라는 뜻이에요. 이 교재는 클라우드 모델이나 API 키를 사용하지 않습니다. 다운로드를 마치면 인터넷을 끊고도 시험할 수 있어요.

컴퓨터 사양이 낮아 아주 느리다면 교사가 qwen2.5:0.5b로 바꿔 실습할 수 있습니다. 그 경우 pull 명령과 두 Python 코드의 model/MODEL 이름을 모두 같은 값으로 바꾸세요. 작은 모델은 답의 품질이 떨어질 수 있습니다.

BUILD 07

③ Arduino 최종 코드 업로드

이 코드는 0~1023을 0.2초마다 PC에 보내고, PC에서 G·Y·R을 받으면 해당 LED를 켭니다. X는 오류가 났을 때 모두 끕니다. 온도를 계산하거나 AI를 실행하는 곳은 Python입니다.

robot_led.ino최종 Arduino 스케치 · 업로드 후 시리얼 모니터 닫기
// AI 우주 탐사 로봇 신호등 · Arduino UNO R3/R4 기본 10비트 읽기
const int POT_PIN = A0;
const int RED_PIN = 8;
const int YELLOW_PIN = 9;
const int GREEN_PIN = 10;
unsigned long lastSample = 0;

void allOff() {
  digitalWrite(RED_PIN, LOW);
  digitalWrite(YELLOW_PIN, LOW);
  digitalWrite(GREEN_PIN, LOW);
}

void setup() {
  pinMode(RED_PIN, OUTPUT);
  pinMode(YELLOW_PIN, OUTPUT);
  pinMode(GREEN_PIN, OUTPUT);
  allOff();
  Serial.begin(9600);
  Serial.setTimeout(30);
}

void loop() {
  // 가변저항 값을 숫자와 줄바꿈으로 PC에 보낸다.
  if (millis() - lastSample >= 200) {
    lastSample = millis();
    Serial.println(analogRead(POT_PIN));
  }

  // PC에서 보낸 G/Y/R/X 한 글자를 받는다.
  if (Serial.available() > 0) {
    char command = Serial.read();
    if (command == 'G' || command == 'Y' || command == 'R' || command == 'X') {
      allOff();
      if (command == 'G') digitalWrite(GREEN_PIN, HIGH);
      if (command == 'Y') digitalWrite(YELLOW_PIN, HIGH);
      if (command == 'R') digitalWrite(RED_PIN, HIGH);
    }
  }
}
업로드만 하고 아직 LED가 꺼져 있어도 정상이에요. Python이 색 명령을 보내기를 기다리는 중입니다.

⑤ Python에서 Ollama에게 말 걸기

이번에는 Arduino와 관계없이 Python이 Ollama의 로컬 API에 요청하는지 시험합니다. check_ai.py로 저장하고 실행하세요. 이 예제에서 Ollama는 바깥쪽 응답 JSON의 response 항목에 답을 넣어 줍니다.

Arduino에는 이미 robot_led.ino가 업로드되어 있어야 합니다. 아래 Python 코드를 robot_ai.py로 저장하고 맨 위 PORT = "COM3"를 내 번호로 바꾸세요. 시리얼 모니터는 닫은 상태에서 실행합니다.

손잡이를 돌린 뒤 약 1초간 멈춰 주세요. Python은 20~80도의 가상 온도로 바꾸고, 5도 구간이 달라지면 AI에게 묻습니다. AI 응답을 기다리는 동안 LED는 잠깐 꺼집니다. AI가 말하는 사이 손잡이를 크게 바꿨다면 오래된 답을 버리고 다시 질문합니다.

robot_ai.py최종 Python 코드 · COM 포트 수정
"""Arduino UNO + local Ollama: fictional robot battery temperature demo."""
import json
import time
import urllib.error
import urllib.request

import serial

PORT = "COM3"  # 자신의 Arduino IDE에 표시된 포트로 바꾸기
BAUD = 9600
MODEL = "qwen2.5:1.5b"
URL = "http://127.0.0.1:11434/api/generate"

SCHEMA = {
    "type": "object",
    "properties": {
        "light": {"type": "string", "enum": ["G", "Y", "R"]},
        "message": {"type": "string"},
    },
    "required": ["light", "message"],
    "additionalProperties": False,
}


def temperature(raw):
    return 20 + round(raw * 60 / 1023)


def safe_light(temp):
    if temp < 40:
        return "G"
    if temp < 60:
        return "Y"
    return "R"


def latest_raw(board):
    """기다리는 동안 쌓인 측정값 중 가장 최근의 숫자를 돌려준다."""
    line = board.readline()
    while board.in_waiting:
        line = board.readline()
    try:
        raw = int(line.decode("ascii").strip())
    except (UnicodeDecodeError, ValueError):
        return None
    return raw if 0 <= raw <= 1023 else None


def ask_ai(temp):
    payload = {
        "model": MODEL,
        "system": (
            "초등학생의 가상 우주 로봇 배터리 온도 관제 연습이다. "
            "실제 배터리 측정이나 안전 기준이 아니다. "
            "20~39도는 G, 40~59도는 Y, 60~80도는 R로 답하라. "
            "message에는 온도를 넣고 짧고 친절한 한국어 한 문장만 써라. "
            "오직 light와 message가 있는 JSON으로 답하라."
        ),
        "prompt": f"가상 배터리 온도는 {temp}도다. 신호등 색과 안내 문장을 결정해 줘.",
        "format": SCHEMA,
        "stream": False,
        "options": {"temperature": 0},
    }
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8")
    request = urllib.request.Request(
        URL, data=data, headers={"Content-Type": "application/json"}
    )
    with urllib.request.urlopen(request, timeout=90) as response:
        envelope = json.load(response)
    answer = json.loads(envelope["response"])
    if not isinstance(answer, dict):
        raise ValueError("AI 응답이 JSON 객체가 아닙니다.")
    light = answer.get("light")
    message = answer.get("message")
    if light not in ("G", "Y", "R") or not isinstance(message, str):
        raise ValueError("AI 응답의 light 또는 message가 잘못되었습니다.")
    return light, message[:100]


def main():
    print("연결 중...", PORT, "(종료: Ctrl+C)")
    with serial.Serial(PORT, BAUD, timeout=0.35) as board:
        time.sleep(2)  # 포트를 열 때 Arduino가 재시작될 수 있다.
        board.reset_input_buffer()
        candidate = None
        candidate_since = 0.0
        last_sent = None
        while True:
            raw = latest_raw(board)
            if raw is None:
                continue
            temp = temperature(raw)
            bucket = temp // 5  # 5도 구간이 달라졌을 때 다시 AI에 묻는다.
            if candidate != bucket:
                candidate = bucket
                candidate_since = time.monotonic()
                print(f"가변저항 {raw:4} → 가상 온도 {temp}도 (잠시 유지!)")
            if bucket == last_sent or time.monotonic() - candidate_since < 0.8:
                continue
            board.write(b"X\n")  # 새 답을 기다리는 동안 이전 색을 끈다.
            print(f"AI에게 {temp}도를 질문 중... (LED 대기)")
            try:
                proposal, message = ask_ai(temp)
            except (urllib.error.URLError, TimeoutError, KeyError,
                    ValueError, json.JSONDecodeError) as exc:
                board.write(b"X\n")  # AI 통신 오류는 LED 모두 끔
                print("AI 연결/응답 오류:", exc)
                last_sent = None
                time.sleep(2)
                continue
            # AI가 답하는 사이 손잡이가 바뀌었다면 낡은 답은 사용하지 않는다.
            fresh = latest_raw(board)
            if fresh is not None and temperature(fresh) // 5 != bucket:
                print("값이 바뀌어서 이전 AI 답을 버립니다.")
                candidate = None
                continue
            verified = safe_light(temp)
            if proposal != verified:
                print(f"AI 제안 {proposal}은 약속한 기준과 달라 {verified}로 고칩니다.")
            board.write((verified + "\n").encode("ascii"))
            print(f"AI 제안 {proposal} | 실제 LED {verified} | {message}")
            last_sent = bucket


if __name__ == "__main__":
    try:
        main()
    except KeyboardInterrupt:
        print("\n실습을 종료합니다.")
    except serial.SerialException as exc:
        print("시리얼 연결 오류:", exc)
        print("COM 포트, USB 케이블, 시리얼 모니터 닫힘 여부를 확인하세요.")

막혔을 때와 다음 도전

python 또는 py가 인식되지 않아요

새 cmd를 연 뒤 다시 확인하세요. 설치 화면의 Add Python to PATH와 launcher 설치를 확인합니다. py -3.11 --version이 동작하면 교재 명령은 그대로 쓸 수 있습니다.

No module named serial

py -3.11 -m pip install pyserial을 다시 실행합니다. 파일 이름을 serial.py로 저장하면 충돌하므로 다른 이름을 사용합니다.

COM 포트를 열 수 없어요 / PermissionError

Arduino IDE의 시리얼 모니터·플로터와 다른 Python 프로그램을 닫습니다. IDE에서 COM 번호를 다시 보고 PORT를 수정합니다. USB 데이터 케이블도 확인하세요.

Connection refused 또는 Ollama가 응답하지 않아요

Windows 시작 메뉴에서 Ollama를 실행하고 ollama ls를 확인합니다. Ollama 앱이 완전히 종료된 상태에서 직접 서버를 띄울 때만 ollama serve를 사용하세요. 이미 실행 중이면 11434 포트 충돌이 날 수 있습니다.

model not found 또는 AI 답이 너무 느려요

ollama ls에서 모델 이름을 확인하고 없다면 ollama pull qwen2.5:1.5b를 실행하세요. 첫 응답이 느릴 수 있으니 기다립니다. 저사양 PC는 교사가 0.5b 모델로 바꿀 수 있습니다.

가변저항을 움직여도 LED가 바로 안 변해요

손잡이를 1초 이상 고정하고 AI가 답할 때까지 기다리세요. 같은 5도 구간 안에서는 질문을 다시 보내지 않습니다. 프로그램이 끝나거나 연결이 끊기면 LED가 마지막 색으로 남을 수 있으므로 USB를 뽑아 종료하세요.

숫자가 0~1023이 아니거나 불이 반대로 켜져요

UNO R3/R4 선택, A0 배선, analogReadResolution을 바꾼 다른 코드가 남아 있지 않은지 확인하세요. HIGH에서 꺼지는 신호등 모듈은 이 실습의 LED 3개 배선과 다릅니다.
